# RAG-Document-Q-A-Chatbot-GenAI
DocMind: a RAG document Q&amp;A chatbot. Upload PDF, DOCX, TXT, MD or CSV files (or use the built-in demo dataset) and ask questions in a sleek animated UI. TF-IDF retrieval, streaming answers with clickable source citations, offline mode plus optional Claude/OpenAI. Built with FastAPI, scikit-learn and vanilla JS.
